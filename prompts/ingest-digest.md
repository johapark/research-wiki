# Digest-path ingest fallback — `researchwiki ingest`

**Default path is `researchwiki agent ingest`** (see CLAUDE.md → Operations → Ingest). Use the digest path **only** when:

- **Recovery**: re-ingest with `--doi`/`--title`/`--authors` overrides after stem-derivation failure (see [`recovery.md`](./recovery.md)).
- **Unextractable PDFs**: `pypdfium2` returns near-empty/gibberish; build from S2 `abstract`. Set `pdf_extraction_note:` (say what the page was built from instead) + `abstract_source: semantic-scholar`. Those two fields are the whole record — `researchwiki status` lists every page carrying the note, so there's no ledger file to update.
- **Special page types**: synthesis (`researchwiki synthesize`), reference docs (manual) — neither uses ingest paths.
- **Custom voice**: rare; agent's framing doesn't fit. Justify in `log.md`.

```bash
researchwiki ingest inbox/<raw-filename>.pdf --category <category>
# 1. Read .ingest/{stem}-digest.md
# 2. Write wiki/{category}/{stem}.md in a single Write call
# 3. Manually back-link every incoming cross-link on the citing page
# 4. rm .ingest/{stem}-digest.md
# 5. researchwiki lint --fix
# 6. researchwiki evolve cgt/{stem}   (agent path runs this automatically)
# 7. researchwiki db rebuild && researchwiki reindex
```

Manual back-link reconciliation is error-prone — `lint --fix` inserts placeholder `(auto-added; refine)` bullets that decay. Avoid for routine ingest.

## Page contract — what to write

YAML is strict — **no unquoted `": "` inside any value.** Most common offender: a paper **title with a colon-space subtitle** (`MemGPT: Towards LLMs as Operating Systems`) — always wrap `title:` in double quotes (as the template below does), or the whole frontmatter fails to parse. Same rule elsewhere: use `senior_authors:` rather than `authors: X, Y, et al. (senior: Z)` — the colon-space inside parens parses as nested mapping and breaks Obsidian's structured view. When manually promoting a sandbox page (`.agent-output/` → `wiki/`), re-check the `title:` is quoted before moving.

```yaml
---
title: "Paper Title"
authors: Author list
senior_authors: Senior-author list    # optional
consortium: Consortium Name           # optional
year: YYYY
doi: DOI
venue: "Journal Name"                 # omit if the paper has none (preprint); never record typesetting furniture — `lint` flags it as `venue_suspect`
type: paper                           # REQUIRED. A page with no `type:` reads as `paper` to every consumer via `fm.get("type", "paper")`, so the field going missing is silent — and on a commentary it misattributes the primary authors' claims. `lint`'s `missing_type` is the only check that sees it.
category: [your-category]
pdf_path: "[[{stem}.pdf]]"    # Obsidian wikilink → click-to-open in the vault (papers/ sits beside wiki/). Quote it: a leading [[ is otherwise parsed as a YAML flow sequence. db rebuild derives the real path from the stem.
short_name: MemGPT                    # optional: the paper's own short handle, for index.md
hook: "..."                           # the index.md gloss. Always double-quote it — hooks routinely carry [[wikilinks]] and `:`. Result-first, ≤400 chars for a paper page. See CLAUDE.md → Ingest → Step 3; do NOT paste the digest's tldr-seeded draft through.
keywords: [retrieval, tokens, distinctive, phrases]   # 5–10 specific search terms; auto-generated by ingest
author_model: "claude-sonnet-4-6"   # the LLM model that authored this page (you, when filling this digest in). Use the exact model id; quote it. Distinct from `authors:` (paper authors).
ingested_at: 2026-04-15T14:30:00    # ISO 8601 local, UNQUOTED (a real YAML timestamp). Stamp with `date +%Y-%m-%dT%H:%M:%S`.
---

## Summary
<!-- ≤150 words. The "what, how, why-it-matters". Use terminology a future search query would plausibly use. -->

## Key Contributions
<!-- ≤10 bullets. Each: a concrete claim + a number or comparison. Facts over adjectives. -->

## Methodology and Architecture
<!-- ≤300 words. Only the parts that differentiate from standard workflow in the field. -->

## Results
<!-- ≤300 words. Top 5–8 numbers with brief context. Tables preferred for benchmarks. -->

## Limitations
<!-- ≤100 words. Bulleted. What the paper acknowledges + obvious gaps. -->

## Related Papers
<!-- ≤6 entries. [[wikilink]] only if in this wiki AND the current paper cites it or is cited by it. -->
- [[category/page]] — one-line relationship + direction of citation
```

**Section caps are budgets, not minimums.** Drop sections that aren't earning their tokens.

**The four H2 names above are matched exactly** by claim extraction (`grade/parser.py`'s
`SECTION_KEYS`). A page that renames one — `## Findings` for `## Results` — yields no claims
from it, is uncitable, and is invisible to `ungraded_papers`; `lint`'s `zero_claim_papers` is
what catches it. Same reason the digest path must set `type:` and `hook:` by hand: the agent
path writes both and the template is the only place this path gets told to.

**Foundational-paper override.** If the paper introduces **≥2 substantially novel contributions** (new architecture *and* new dataset, etc.), Methodology/Results/Key Contributions caps extend up to **1.5×**. Summary (≤150 w) and Limitations (≤100 w) stay fixed. Use sparingly.

The agent path enforces this contract automatically; the digest path requires you enforce by hand.
