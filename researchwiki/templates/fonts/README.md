# Reader fonts

## Source Serif 4

Unmodified variable Roman and Italic WOFF2 fonts from Adobe's 4.005R release.
Source: https://github.com/adobe-fonts/source-serif/releases/tag/4.005R
Archive: https://github.com/adobe-fonts/source-serif/releases/download/4.005R/source-serif-4.005_WOFF2.zip

## SNUJaha

Version 0.2.2, supplied in `inbox/SNUJaha-0.2.2.zip` by the user.
Internal family name: `SNU Jaha`. Derived from RIDIBatang and Roboto Serif,
with modifications by Hyeshik Chang.

Regular (400), SemiBold (600), and Bold (700), each upright and italic, were
converted from OTF to WOFF2 using fontTools 4.68.0 and brotli 1.2.1. No subsetting:
the original character maps, glyph order, font name records, weights, and italic
metadata are preserved, including full Korean coverage.

License: SIL Open Font License 1.1, permitting commercial use and redistribution
with the notices retained. See `SNUJaha-LICENSE.txt` and the supplied upstream
notices `SNUJaha-LICENSE-RIDIBatang.txt` and `SNUJaha-LICENSE-RobotoSerif.txt`.

## Delivery

Live dashboards serve these packaged files locally. Offline HTML embeds them as
data URLs and retains all license notices. No external font requests are made.
Live browsers load only faces needed for the selected reader font.
